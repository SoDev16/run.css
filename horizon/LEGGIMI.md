# Titanio Vero — thème Horizon (brouillon)

Fichiers destinés au thème **« Titanio Vero — travail »**
(`gid://shopify/OnlineStoreTheme/203983520092`), copie non publiée de Horizon
sur `t3dz1k-jv.myshopify.com`.

L'arborescence reproduit celle du thème Shopify : `config/`, `blocks/`,
`sections/`, `assets/`, `templates/`.

Les fichiers sont envoyés à Shopify par URL brute GitHub épinglée sur le SHA
du commit, ce qui évite tout problème de cache.
