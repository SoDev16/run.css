Renseigné, le badge affiche automatiquement « Plus que X € pour la livraison offerte » tant que le panier est en dessous.

Autonome : à coller dans un bloc « Liquid personnalisé » de l'éditeur de thème.

  1. Le plus simple — Boutique › Thèmes › Personnaliser, page Produit, Ajouter un bloc › Liquid personnalisé, placez-le sous le prix et collez l'onglet « Bloc Liquid personnalisé ».
  2. Version réutilisable — Thèmes › Modifier le code › snippets › Ajouter un fichier nommé livraison-offerte, collez l'onglet du milieu, enregistrez.
  3. Appelez-le ensuite où vous voulez (par ex. dans sections/main-product.liquid, juste après le bloc du prix) :
    {% render 'livraison-offerte' %}
  4. Avec des options : {% render 'livraison-offerte', texte: 'Livraison offerte dès 49 €', couleur: '#0E9F6E', taille: 14 %}
  5. Avec le compte à rebours du panier — le seuil est en centimes : {% render 'livraison-offerte', seuil: 4900 %}
  6. La pastille s'arrête pour les visiteurs qui demandent moins d'animations (prefers-reduced-motion), et elle est masquée aux lecteurs d'écran : le texte suffit.
Testé sur fond clair et sur fond sombre. Le badge n'utilise aucune image ni script : uniquement du Liquid et du CSS.
